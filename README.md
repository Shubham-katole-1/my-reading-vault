# 📚 VaultScans — Personal Media Vault

A lightweight, dark-themed, serverless library web application to track and organize your personal collection of **Manhwa, Manga, Manhua, Novels, Books, and Movies**. 

Built with **Vanilla JavaScript**, **Tailwind CSS**, and **GitHub Pages** — $0 host, zero dependencies, and lightning fast.

---

## ✨ Features

- 🔍 **Real-Time Search:** Search titles instantly by name.
- 🏷️ **Category Tabs:** Filter by *Manhwa, Manga, Manhua, Novel, Web-Novel, Book, or Movie*.
- 🎭 **Genre Filtering:** Filter by 18+ custom genres (e.g., *Murim, Crazy MC, Overpowered, Dark Fantasy, Dungeons*).
- 📌 **Status Badges:** Color-coded badges for *Ongoing* and *Completed* series.
- ⚡ **Sorting:** Sort entries by Highest Rating or Alphabetical order (A–Z).
- 🎨 **AsuraScans-Inspired UI:** Modern dark mode interface designed with Tailwind CSS.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS (via CDN)
- **Logic:** Vanilla JavaScript (Fetch API, ES6+)
- **Database:** `data.json`
- **Hosting:** GitHub Pages
